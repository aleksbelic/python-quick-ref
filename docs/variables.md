# Variables

Variables store values under a name. Python creates a variable on assignment — no declaration or type keyword needed.

## Creating variables

Assign with `=`. An `int` needs no quotes, a `str` does.

```python
x = 123
y = 'this is a string'
```

## Printing variables

Pass variables to `print()` to display their values.

```python
print(x, y)  # '123 this is a string'
```

!!! tip "Dynamic typing"
    A variable takes the type of the value assigned to it, and can be reassigned
    to a value of a different type later.
